# ちょなちょナゲット 注文管理アプリ

学祭の店頭iPadで注文と会計を受け、パソコンで注文内容、受付番号1〜10、売上を管理するブラウザアプリです。

## できること

- 日付別の味を選び、カップ数・個数・合計金額を自動計算
- 現金またはPayPayを選んで、注文と売上を同時登録
- 受付番号を1→10の順で循環し、使用中の番号を飛ばして自動割り当て
- 10組受付中は新しい注文を停止
- 管理画面で注文ごとに「受け取り完了」または「取消」を操作
- 完了・取消済みの注文履歴を1件ずつ削除
- 完了・取消後に受付番号を再利用
- 総売上、現金、想定PayPay、会計件数、販売カップ数を集計
- 味ごとの販売カップ数と割合を表示
- 売上履歴の取消とCSVダウンロード
- iPadとパソコンへリアルタイム反映
- 注文端末・管理者を別アカウントで保護

## 当日の使い方

### iPad（注文・会計）

1. 味とカップ数を選び「お会計へ」を押します。
2. 現金またはPayPayを選び、「売上を登録して受付番号を発行」を押します。
3. 表示された番号札を渡し、「次の注文へ」を押します。

PayPayの実際の入金はPayPayアプリで確認してください。このアプリには想定PayPay売上として記録されます。

### パソコン（管理）

- 「注文管理」で、受け渡し完了または取消を操作します。
- 「売上管理」で、日別・2日間合計、支払い別売上、味別割合を確認します。
- 誤った売上は削除せず「売上取消」にします。必要に応じてCSVを保存できます。
